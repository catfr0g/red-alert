## Purpose

Текстовый отчёт прогона: ASR, цепочка шагов и доказательства. При `--output` тот же текст пишется в UTF-8 файл.

## Requirements

### Requirement: Отчёт с вердиктом и ASR

СИСТЕМА ДОЛЖНА (MUST) печатать в stdout итог прогона: число успешных попыток, число всех попыток и ASR.

#### Scenario: Все попытки успешны

- **WHEN** выполнены две попытки и обе успешны
- **THEN** отчёт показывает 2 успешные из 2 и ASR 100%

#### Scenario: Часть попыток успешна

- **WHEN** выполнены две попытки и успешна только одна
- **THEN** отчёт показывает 1 успешную из 2 и ASR 50%

#### Scenario: Нет успешных попыток

- **WHEN** выполнена одна неуспешная попытка
- **THEN** отчёт показывает 0 успешных из 1, ASR 0% и код выхода 0

### Requirement: Цепочка шагов в отчёте

СИСТЕМА ДОЛЖНА (MUST) для каждой попытки печатать упорядоченные шаги с именем, URL без секрета, телом запроса без заголовка авторизации и телом ответа.

#### Scenario: Успешная попытка содержит полную цепочку

- **WHEN** попытка прошла payload-сообщения, finalize и trigger
- **THEN** в отчёте есть шаги payload, finalize и trigger в этом порядке с запросами и ответами

#### Scenario: Обрыв цепочки при ошибке

- **WHEN** payload вернул HTTP 500
- **THEN** в отчёте попытки есть шаг payload с ошибкой и нет последующих шагов finalize и trigger

### Requirement: Коды выхода CLI

СИСТЕМА ДОЛЖНА (MUST) завершать успешный прогон кодом 0 даже при ASR 0% и использовать код 2 только для ошибок ввода.

#### Scenario: Прогон с нулевым ASR

- **WHEN** сценарий выполнен и ни одна попытка не успешна
- **THEN** процесс завершается с кодом 0 и отчёт напечатан

#### Scenario: Ошибка ввода

- **WHEN** отсутствует ключ атакующего, отсутствует ключ жертвы, ключи совпадают или указан неизвестный сценарий
- **THEN** процесс завершается с кодом 2 и отчёт об атаке не печатается

### Requirement: Файл отчёта в UTF-8

СИСТЕМА ДОЛЖНА (MUST) при заданном `--output` сохранять отчёт в указанный файл в UTF-8 без зависимости от кодировки оболочки.

#### Scenario: Секреты скрыты и в файле

- **WHEN** отчёт пишется в файл через `--output`
- **THEN** в файле нет значений API-ключей в открытом виде
