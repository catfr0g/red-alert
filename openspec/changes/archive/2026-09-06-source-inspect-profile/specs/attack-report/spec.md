## ADDED Requirements

### Requirement: Отчёт показывает отсечённые сценарии

СИСТЕМА ДОЛЖНА (MUST) печатать список skipped: имя шаблона и причину (`requires <capability>` или незаполненный слот). ASR и поля `successful` / `total` считаются только по запущенным попыткам. JSON содержит массив `skipped` с `name` и `reason`. Если все шаблоны отсечены, JSON-отчёт атаки не печатается — это ошибка ввода (код 2).

#### Scenario: Часть каталога отсечена

- **WHEN** прогон без `--scenario` запускает два сценария и пропускает один из-за `vision`
- **THEN** в консоли есть skipped с именем и причиной, суммарный ASR считается по попыткам двух запущенных, в JSON есть `skipped`

#### Scenario: ASR не включает skipped

- **WHEN** один сценарий пропущен и один выполнен с 0 успехов из 1 попытки
- **THEN** ASR равен 0%, `total` равен 1, пропущенный не входит в `total`

#### Scenario: Один запущенный сценарий без skipped

- **WHEN** задан `--scenario` и шаблон собран
- **THEN** JSON по-прежнему содержит поле `scenario`; `skipped` — пустой массив или отсутствует
