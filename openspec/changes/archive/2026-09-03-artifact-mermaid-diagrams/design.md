## Context

В проекте используются артефакты OpenSpec `proposal.md`, `design.md`, спецификации и `tasks.md`. Правило должно быть доступно и агентам, и командам OpenSpec, которые формируют инструкции для этих артефактов.

## Goals / Non-Goals

**Goals:**

- Установить один формат для диаграмм во всех артефактах OpenSpec.
- Явно указать синтаксис: fenced-блок Markdown с языком `mermaid`.
- Сохранить существующие правила для обычного текста и фрагментов кода.

**Non-Goals:**

- Добавление Mermaid-рендерера, линтера или новой зависимости.
- Автоматическая миграция диаграмм в документах вне артефактов OpenSpec.

## Decisions

- Источником правила для агентов будет `AGENTS.md`.
- Источником контекста и инструкций OpenSpec будет `openspec/config.yaml`.
- Формулировка будет запрещать ASCII-схемы и другие языки описания диаграмм, но не будет запрещать обычные fenced-блоки кода с подходящей языковой меткой.
- Проверка в рамках change выполняется поиском маркеров диаграмм и OpenSpec-валидацией; отдельный автоматический линтер не добавляется.

## Risks / Trade-offs

Правило само по себе не проверяет все будущие изменения автоматически. Это принимаемый компромисс: он не добавляет зависимостей и уже покрывает основные точки, из которых формируются инструкции. Автоматический lint можно оформить отдельным change при появлении такой потребности.
