## MODIFIED Requirements

### Requirement: Сценарий отравления памяти через публичный API

СИСТЕМА ДОЛЖНА (MUST) для YAML с `flow: memory` сгенерировать payload планировщиком, доставить его ключом атакующего, финализировать сессию и проверить поведение ключом другого пользователя.

#### Scenario: Полная цепочка одной попытки

- **WHEN** запускается сценарий с `flow: memory`
- **THEN** система последовательно: вызывает планировщик; отправляет payload в чат сессии A ключом атакующего; вызывает finalize сессии A; отправляет trigger в сессию B ключом жертвы

#### Scenario: Payload направлен на цель YAML

- **WHEN** система отправляет payload атакующего
- **THEN** текст соответствует цели загруженного сценария
