## MODIFIED Requirements

### Requirement: Запуск атаки из командной строки

СИСТЕМА ДОЛЖНА (MUST) предоставлять команду `red-alert attack` с параметрами цели, ключа атакующего, ключа жертвы, сценария (имя YAML или путь), необязательного каталога атак, числа попыток и необязательного файла отчёта.

#### Scenario: Успешный запуск с полными аргументами

- **WHEN** пользователь выполняет `red-alert attack --target <url> --api-key <attacker> --victim-api-key <victim> --scenario memory-poisoning`
- **THEN** система запускает сценарий против указанного URL и печатает отчёт в stdout

#### Scenario: Каталог атак из окружения

- **WHEN** задана `RED_ALERT_ATTACKS_DIR` и `--attacks-dir` не передан
- **THEN** система ищет YAML в этом каталоге

#### Scenario: Неизвестный сценарий

- **WHEN** пользователь указывает `--scenario` со значением, для которого нет YAML
- **THEN** система не выполняет HTTP-запросы, пишет ошибку в stderr и завершается с кодом 2
