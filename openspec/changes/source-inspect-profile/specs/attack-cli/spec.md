## ADDED Requirements

### Requirement: Профиль задаётся флагом или умолчанием

СИСТЕМА ДОЛЖНА (MUST) принимать `--profile` / `RED_ALERT_PROFILE` как путь к StandProfile. Флаг перекрывает переменную. Если ни флаг, ни переменная не заданы, используется упакованный `invest-stand`. Невалидный профиль — код 2 без HTTP к стенду.

#### Scenario: Флаг профиля

- **WHEN** пользователь указывает `--profile custom.yaml` с валидным профилем
- **THEN** система применяет `custom.yaml` при сборке сценариев

#### Scenario: Профиль из окружения

- **WHEN** задана `RED_ALERT_PROFILE` и `--profile` не передан
- **THEN** система читает этот путь

#### Scenario: Умолчание invest-stand

- **WHEN** профиль не задан
- **THEN** `red-alert attack --scenario memory-poisoning` собирает экземпляр из упакованного invest-stand и запускает атаку

### Requirement: Явный сценарий обходит отсечение по capability

СИСТЕМА ДОЛЖНА (MUST) при заданном `--scenario` не пропускать шаблон из-за `absent` capability, если все слоты заполнены. Если слот пустой — код 2 без HTTP.

#### Scenario: Override image-атаки

- **WHEN** в профиле `vision=absent` с высокой уверенностью и пользователь задаёт `--scenario memory-poisoning-image-injection` с заполненными слотами
- **THEN** система запускает этот сценарий

#### Scenario: Override без слота

- **WHEN** `--scenario` указывает шаблон с пустым слотом в профиле
- **THEN** система не выполняет HTTP, пишет ошибку про слот и завершается с кодом 2

## MODIFIED Requirements

### Requirement: Прогон всего каталога по умолчанию

СИСТЕМА ДОЛЖНА (MUST) при отсутствии `--scenario` загрузить все YAML из каталога атак в алфавитном порядке имён, применить профиль, выполнить каждый собранный сценарий с указанным `--attempts` и не запускать skipped. Явный `--scenario` запускает только выбранный шаблон (с обходом capability). Пустой каталог, невалидный YAML или отсутствие собранных сценариев после фильтра останавливают прогон с кодом 2 без HTTP.

#### Scenario: Запуск без --scenario

- **WHEN** пользователь выполняет `red-alert attack` без `--scenario` и профиль оставляет несколько техник
- **THEN** система выполняет каждый собранный сценарий по очереди, в прогрессе видно имя текущего, в итоге есть все запущенные имена

#### Scenario: Явный один сценарий

- **WHEN** пользователь указывает `--scenario memory-poisoning`
- **THEN** система выполняет только этот сценарий

#### Scenario: Пустой каталог

- **WHEN** `--scenario` не задан и в каталоге нет YAML
- **THEN** система не выполняет HTTP, пишет ошибку в stderr и завершается с кодом 2

#### Scenario: Попытки на каждый сценарий

- **WHEN** пользователь указывает `--attempts 3` без `--scenario` и профиль оставляет два шаблона
- **THEN** система делает три попытки первого сценария и три попытки второго

#### Scenario: После фильтра нечего запускать

- **WHEN** `--scenario` не задан и профиль отсекает все шаблоны
- **THEN** система не выполняет HTTP, пишет skipped в stderr и завершается с кодом 2
