# Задачи

## 1. CLI запуска PoC

- [ ] 1.1 Создать пакет red_alert и установленную точку входа команды
  red-alert.
- [ ] 1.2 Реализовать команду attack с обязательным параметром --scenario и
  единственным поддержанным значением memory-poisoning.
- [ ] 1.3 Зафиксировать способ передачи API-ключа из runtime-конфигурации после
  решения открытого вопроса и не печатать ключ.
- [ ] 1.4 Реализовать коды завершения success, not_reproduced и error и
  обработку ошибок аргументов.
- [ ] 1.5 Добавить тесты CLI для поддержанного сценария, неизвестного сценария,
  отсутствующего ключа и отсутствующего --scenario.

## 2. Клиент chat completions

- [ ] 2.1 Реализовать типы и формирование тела с полями model, messages,
  session_id, auth_mode и stream=false.
- [ ] 2.2 Реализовать Bearer-авторизацию и запрос только на
  http://localhost:8600/v1/chat/completions.
- [ ] 2.3 Реализовать конечный timeout, проверку HTTP-статуса и разбор
  choices[0].message.content.
- [ ] 2.4 Реализовать типизированные ошибки сети, timeout, HTTP и протокола без
  повторной отправки запроса.
- [ ] 2.5 Добавить mock-тесты точного тела, заголовков, валидного ответа и
  невалидных или ошибочных ответов; отдельно проверить отсутствие вызовов
  /memory и прямой ручки финализации.

## 3. Сценарий memory poisoning

- [ ] 3.1 Реализовать модели запуска, шага, запроса, ответа, ошибки и
  трассировки.
- [ ] 3.2 Зафиксировать payload, команду finalize, trigger и regex-предиктор
  в сценарии без LLM-планировщика.
- [ ] 3.3 Реализовать две разные сессии под одним API-ключом: сессию A для
  payload и finalize и сессию B для trigger.
- [ ] 3.4 Реализовать ровно три chat-запроса в порядке payload → finalize →
  trigger с отдельным messages для каждого шага.
- [ ] 3.5 Реализовать остановку после ошибки payload или finalize и сохранение
  частичной трассировки.
- [ ] 3.6 Добавить тесты порядка запросов, session_id, содержимого finalize,
  отсутствия переноса истории и запрета прямых memory-вызовов.

- [ ] 4.3 Сохранить в результате ссылки на шаги, session_id, ответы и
